# RAG

## 기능

- 사용자들이 자신이 알고 있는 지식들을 파일, 텍스트 등의 다양한 형태로 인풋을 제공한다

- 위의 자료들을 임베딩해서 벡터 DB에 저장한다. postgreSQL, 참고: https://discuss.pytorch.kr/t/gn-postgresql-rag-feat-pgdash/4449

- 임베딩 모델은 bge-m3을 사용한다.(한국어 최적)

- 사용자들이 해당 주제에 대해 질문을 하면 DB에 저장된 내용을 바탕으로 벡터 저장소를 검색을 하고, 해당 검색 결과로 컨텍스트와 프롬프트를 만들고, LLM에 질문을 한다.

- LLM은 이 컨텍스트와 프롬프트를 바탕으로 답변을 구성한다

- LLM 답변에 대해 사용자가 피드백을 주면 기존 벡터 DB에 저장된 데이터를 수정하거나 고치는 피드백 기능도 제공한다. (잘한 답변의 경우 점수 더 주고.)
